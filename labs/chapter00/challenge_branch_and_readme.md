# Challenge lab: work on a branch

Real teams do not commit straight to the main branch. They make a branch, do their
work, and merge it back. Practice that loop now.

## Task

1. Create and switch to a new branch called `add-readme`.
2. On that branch, create a `README.md` that says what the repository is (one or two
   sentences is fine).
3. Stage and commit the README on the branch.
4. Push the branch to GitHub with `git push -u origin add-readme`.
5. On GitHub, open the pull request that compares `add-readme` to `main`, then merge
   it.
6. Back on your machine, switch to `main` and pull the merged change down.

## What to hand in

The commands you ran, and a note on what a branch let you do that committing straight
to main would not.

The solution is in `solutions/chapter00/challenge_branch_and_readme_solution.md`.
