# Student exercise: make a second commit

You have made your first commit. Now prove you can repeat the save loop on your own,
because you will do it hundreds of times in this course.

## Task

1. Make sure your virtual environment is active and you are in the project folder.
2. Add a new line to `requirements.txt` so it lists both `ipython` and `rich`
   (rich is a library the course uses later for nicer output).
3. Actually install rich into your environment with pip.
4. Stage and commit only the change to `requirements.txt`, with a clear message.
5. Push the commit to GitHub and confirm the change shows up online.

## What to hand in

The exact commands you ran, in order, and the commit message you used.

The solution is in `solutions/chapter00/exercise_second_commit_solution.md`. Try it
first before you look.
